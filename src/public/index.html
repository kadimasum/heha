Continuous Integration & Continuous Delivery

This application is a working example used to demonstrate how code moves from a developer's commit to a running service in production — automatically, safely, and repeatably.

What is CI/CD?

Continuous Integration

Every code change is automatically built and tested as soon as it is pushed, catching issues early and keeping the main branch always in a releasable state.

Continuous Delivery

Validated builds are automatically packaged into deployable artifacts — such as container images — ready to be released at any time.

Continuous Deployment

Approved artifacts are automatically rolled out to the target environment (e.g. Kubernetes) with zero manual steps and no downtime.
